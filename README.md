Vesta is a powerful, modular Discord bot designed for performance, safety, and fun. Packed with anti-nuke, anti-raid protection, economy & roleplay systems, and tons of utilities — it's the only bot your server will ever need.

Heavily modified fork of Juno/Kayo made by Ethan. Contains a lot of rewritten code as well as introduced a Clustering/IPC for large bots.

---

## 🚀 Features

### 🛡️ Security
- **Anti-Nuke:** Protects your server from mass-ban/kick attempts.
- **Anti-Raid:** Detects and prevents raid-style joins & spam.

### 💰 Economy
- Virtual currency with earning, spending, and trading.
- Jobs, daily rewards, shops, and leaderboards.

### 🎭 Roleplay
- Pet system, relationship commands, roleplay actions (hug, slap, etc.)

### 🎉 Fun
- Memes, jokes, 8ball, image manipulations, games and more.

### ⚙️ Utility
- Server info, user info, poll creation, reminders, timers.
- Moderation tools (kick, ban, mute, warn) with logging.
- Role management, embed builder, and much more.
- Log moderation actions as well as actions taken within your server.

## 🧠 Tech Stack

- **Language:** Python 3.12+
- **Library:** [discord.py](https://discordpy.readthedocs.io/)
- **Database:** PostgreSQL (asyncpg)
- **Cache / Queue:** Redis (aioredis)
- **Storage Solution:** Minio (S3)
